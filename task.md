# Full Stack Developer Internship - Take-Home Assignment

Welcome, and thank you for your interest in the Full Stack Developer Internship! To evaluate your practical coding skills, we've designed a short take-home assignment. This project is an opportunity to showcase how you work with third-party APIs, integrate libraries, and build clean user interfaces.

## Step 1: Account Setup & API Exploration

a) Generate a temporary email address using Guerrilla Mail.
b) Use this temporary email to create a new Reddit account. Make sure to verify the account with the code on Guerrilla Mail.
c) Explore the Reddit API documentation to understand how to fetch subreddit data.

## Step 2: Build the Dashboard with Following Core Functionality

Your task is to build a web application called "The Subreddit Vibe Check". You may use the frontend framework of your choice.

### a) Data Fetching
Allow the user to input or select a subreddit. Fetch the top 50 "Hot" posts of that chosen subreddit using the `/r/{subreddit}/hot` endpoint.

### b) Sentiment Analysis
Run a simple client-side sentiment analysis library on the titles of these 50 posts. Display the results clearly on the dashboard.
